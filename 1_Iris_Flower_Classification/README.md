Iris Flower Classification
​ This project uses Machine Learning to classify Iris flowers into three species: Setosa, Versicolor, and Virginica based on their sepal and petal measurements.

​Project Overview:
 ​The goal is to implement a supervised learning workflow, from data exploration to model evaluation, using the classic Iris Dataset.

Tech Stack:
​Language: Python
​Libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

​Key Features & Workflow:
EDA:
​ Used Box plots and Density plots for Univariate analysis.
​ Scatter plots for Bivariate analysis to see feature relationships.
 ​Checked for missing values and data distribution.

​Data Preprocessing:
 ​Feature Scaling: Standardized numerical values using StandardScaler.
 ​Label Encoding: Converted species names into numerical targets.

​Model Building:
 ​Algorithm: Decision Tree Classifier.
 ​Split data into Training (80%) and Testing (20%) sets.

​Evaluation:
​ Calculated Accuracy, Precision, Recall, and F1-score.
​ Visualized the Decision Tree Map to see how the model makes classification decisions.

​📊 Results & Visualization:
​ The model achieves high accuracy due to clear separation between species (especially Setosa).
 ​The Decision Tree visualization provides an intuitive look at the classification logic.
